# Expedition design and multiplayer fixes

Integrated main through 8972896, preserving its 149 enabled locations, cached photos, panoramas, Mapillary provider, recent-location avoidance, optional Cloudflare match worker, and ten-guess quick mode.

- Redesigned home with destination cards, focused play actions, and map selection.
- Added Quick Escape: five unique places, with a world wildcard finale for SA × NL. Existing saved length settings are retained.
- Country and optional city selection; small maps use their available unique locations.
- Host revisions now own online state. Local pin movement cannot block incoming snapshots; stale locks and continue packets are scoped to their question. Locks retry until acknowledged. Joiners no longer create competing hosts. Host starts explicitly after both players join.
- Browser-session peer identities and host snapshots support refreshing within a room. Private browsing may disable this recovery.
- Fixed hotseat timing and timeout handoffs, bot/hotseat rematches, invalid/late pins, zero-time origins, and unsubmitted timeout scoring (zero).
- Added photo zoom/reset controls; bounded panning and isolated photo keyboard controls from map inputs.
- Fixed relay pagination, database cold-start initialization, retention, per-peer fallback, and visible connection failures.

## Remaining constraints

The integrated catalog contains 149 enabled places. Main’s new cached photographs and fallback chain replace the previously broken external scene links.

P2P private rooms remain host-authoritative. The optional Cloudflare match worker is preserved and typechecked; it requires separate deployment and VITE_MATCH_SERVER_URL configuration, and was not deployed during this update. This is not ranked/anti-cheat secure play: answers can be inferred from the shipped location catalog. Production relay reliability across Vercel instances requires the existing DATABASE_URL configuration. In-memory relay storage is for single-instance development and is not durable.
