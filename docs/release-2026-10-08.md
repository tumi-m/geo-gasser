# TanStack is gone

The game was built on a starter template that brought a web framework
(TanStack Start) and a lot of machinery the game never used. In September that
framework had a security hole that made Vercel stop deploying the site. The
game now runs on plain Vite and React with no framework at all.

## What replaced it

- **Pages:** a hundred lines of our own code (`src/lib/router.tsx`,
  `src/lib/navigation.ts`). It switches between the seven screens with the same
  cross-fade, handles links to a room (`/duel/ABC123`) and the back button,
  sends unknown addresses home, and shows a friendly error screen if a page
  crashes.
- **Server:** one file, `src/server/api.ts`, holds the game's only two
  endpoints: online-duel signaling and the Apple Music token. The signaling
  code is unchanged and uses Postgres when one is configured, exactly as
  before.
- **Build:** `npm run build` runs `vite build`, then `scripts/vercel-output.mjs`
  packages the site plus a single API function for Vercel.
- **Page head:** `index.html` carries the title, description, link-preview
  image, home-screen icon and app manifest. The "Created with Grok" banner the
  template injected into every page is gone.

## What was removed

- **Packages:** 23 fewer (57 → 34), including:
  - TanStack Start, its router and the related TanStack packages
  - Nitro
  - Better Auth
  - Kysely and the PGlite app database (PGlite stays for one test only)
  - 21 Radix UI packages
  - react-hook-form, recharts, sonner, zustand, date-fns, howler, jose
- **Files:** 85 deleted, about 14,500 lines:
  - the TanStack page and API routes (9) and the generated route tree
  - the template's login layer (19) and app-data layer (11)
  - the database bootstrap and migrations
  - the preview bridge
  - the Grok install page and its middleware
  - 26 template scripts

## Checks

- 220 tests pass. Type checks and lint are clean, with no warnings.
- **Production build, served the way Vercel routes it:**
  - every page opens directly and through in-app links, and the back button
    works;
  - full matches play through to results: solo, Grok and pass-and-play;
  - an online duel between two browsers connects through the bundled signaling
    function;
  - Street View works in a build with a key;
  - the accessibility scan is clean.
